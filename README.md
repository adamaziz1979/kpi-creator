# KPI Creator

An AI agent team that takes a business problem from first conversation to a finished, standards-checked KPI dashboard.

- **Garry** gathers requirements and writes the Business Requirements Document
- **Kewpie** builds the top 5 KPIs with SMART targets, linked to business objectives
- **Visalli** picks the right chart for each KPI from a custom template library
- **Jeniffer** builds the HTML dashboard and data story, checked against UX and web build standards
- **Ovy** runs the stages, with an approval gate after each one

Status: in design, 20-Oct-26. Dashboards for the test cases will be published here.
